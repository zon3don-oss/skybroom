# Sky Broom

A fast-paced 3D flying sports game built with Three.js, React Three Fiber and Rapier physics.

## Run it

```bash
npm install
npm run dev
```

## Controls

| Key | Action |
| --- | --- |
| W / S | Speed up / slow down (you always keep moving forward) |
| A / D | Turn left / right |
| Space | Climb |
| Shift | Dive |
